
# LAPORAN PRAKTIKUM 7
## Pemrograman Server-Side dengan PHP

### 1. Tujuan Praktikum
Memahami pemrograman server-side menggunakan PHP, variabel, operator, percabangan, perulangan, function, serta pemrosesan form menggunakan GET dan POST.

### 2. Perangkat yang Digunakan
- Laptop
- XAMPP
- Visual Studio Code
- Google Chrome
- PHP

### 3. Cara Menjalankan Program
1. Membuka aplikasi XAMPP.
2. Menjalankan Apache.
3. Menyimpan folder proyek di htdocs.
4. Membuka folder proyek menggunakan VS Code.
5. Menjalankan file PHP melalui browser dengan localhost.

### 4. Struktur File
- index.php
- latihan2.php
- latihan3.php
- latihan4.php
- cari.php
- latihan6.php
- latihan7.php
- miniproject.php

### 5. Ringkasan Hasil
Seluruh latihan dan mini project berhasil dijalankan menggunakan PHP melalui server lokal XAMPP.

### 6. Pengujian Input

**Input Valid:**
1. Mengisi form dengan data lengkap dan benar.
2. Memasukkan data mahasiswa sesuai format yang diminta.

**Input Tidak Valid:**
1. Mengosongkan kolom wajib pada form.
2. Memasukkan data yang tidak sesuai format.

### 7. Kesimpulan
Praktikum ini memberikan pemahaman tentang dasar pemrograman server-side menggunakan PHP serta pengolahan data melalui form HTML.
